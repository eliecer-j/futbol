# ⚽ Scraper de Eventos + Supabase

## 📌 Descripción
Este proyecto es un script en Python que permite:

- Consumir datos desde una API externa.
- Limpiar información innecesaria.
- Eliminar registros existentes en la base de datos.
- Insertar nuevos datos en Supabase.

Ideal para mantener una tabla actualizada automáticamente (por ejemplo, eventos deportivos).

---

## ⚙️ Tecnologías utilizadas

- Python 3
- requests
- supabase-py
